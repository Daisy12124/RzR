# RzR ✈️

ربات تلگرام شخصی — فقط دانلود کن و استفاده کن.

## ⬇️ دانلود

از صفحه‌ی [Releases](../../releases) آخرین نسخه رو دانلود کن و فایل زیپ رو استخراج کن.

## نصب

1. VPN رو روشن کن (پورت 2080)
2. `RzR.exe` رو اجرا کن
3. با شماره‌ی خودت وارد شو و «اتصال» رو بزن

> راهنمای کامل داخل خودِ بسته‌ی دانلودی (`INSTALL.md`) هست.
