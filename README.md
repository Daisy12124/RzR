# RzR ✈️

ربات تلگرام شخصی — بدون نیاز به برنامه‌نویسی.

## نصب

1. آخرین نسخه رو از [Releases](../../releases) دانلود کن
2. VPN رو روشن کن (پورت 2080)
3. `RzR.exe` رو اجرا کن، شماره‌ات رو وارد کن، کد تأیید رو بزن
4. دکمه‌ی **اتصال** رو بزن — تمام!

راهنمای کامل: [INSTALL.md](INSTALL.md)

## دستورات

`/help` رو داخل تلگرام بزن تا لیست کامل دستورات رو ببینی:
`/music` · `/chat` · `/voice` · `/toimg` · `/togif` · `/sticker` · `/ocr` و ده‌ها مورد دیگه
